# Characters — origin and license

Every file under `godot/winter/assets/characters/` (the hero, the villager with its tint layer, the trader, the
wanderer, the rabbit, the deer, the wolf, the bear; colour sheets and normal maps) is generated by the code in this
folder from primitives (`rig.py`, `humans.py`, `animals.py`, `build.py`) with the shared palette
`tools/winter-godot/palette.py`. No external images, models or textures are used, so the sprites belong to this
project and fall under its license.

Regenerate: `python3 tools/winter-godot/art/characters/build.py` (needs Python 3 with numpy and Pillow; about
two and a half minutes). Look at animations: `python3 tools/winter-godot/art/characters/preview.py OUTDIR hero all 2`.
