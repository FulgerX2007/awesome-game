# Low Poly Winter Pack (Free)
by reodesuxz

Cozy winter and Christmas low poly props: trees, snowman, gifts, igloo, cabin and more.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Winter_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 3112 triangles for all 29 models (24-408 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
